# Karst-forest-mites

### 1. Raw Data

This repository contains the primary datasets for the study. All statistical analyses were performed using these raw data files:  

- (1) *mite.csv* : mite metacommunity data；  
- (2) *m_fungi.csv* : Fungal feeders/ Secondary decomposers community data；  
- (3) *m_predator.csv* : Predator community data；  
- (4) *m_decomp.csv* : Primary decomposer community data；  
- (5) *environment.csv* : Soil environmental variables and sampling site geographical coordinates.  


### 2. Mite Nutritional Functional Groups

*Trophic group.xlsx* file documents the methodology and results for assigning mites to trophic groups. It contains:  

- (1) The application of stable isotope data to classify mite into their respective trophic functional groups；  
- (2) The resulting community parameters (including alpha diversity, beta diversity, network complexity) for each trophic group, calculated using the     averaging method.  


### 3. Network Data & Visualizations

The following folders contain the resources for ecological network analysis in Gephi:  

- (1) *mite meta-community networks* : Data and figures for the meta-community level network;  
- (2) *Local community networks from different forest types* : Data and figures for networks specific to each forest type.  

Each folder includes:  

- (1) Node and edge tables for Gephi;  
- (2) Original visualizations of the networks.
